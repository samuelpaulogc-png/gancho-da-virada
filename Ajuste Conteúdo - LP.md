# **ORIENTAÇÕES GERAIS PARA O DESENVOLVIMENTO**

## **1\. MOBILE FIRST**

Priorizar leitura e conversão pelo celular.

Parágrafos curtos, bastante respiro e botões grandes.

## **2\. CTA RECORRENTE**

Todos os CTAs levam para o mesmo checkout.

Não é necessário usar exatamente o mesmo texto em todos os botões.

## **3\. DESTAQUE PARA O NÚMERO 6**

O elemento **“6 PASSOS”** deve aparecer visualmente em destaque ao longo da página.

É o principal mecanismo da nova campanha.

## **5\. BOTÃO FIXO NO MOBILE**

Após o usuário passar pelo primeiro CTA, inserir um botão fixo discreto na parte inferior:

**QUERO PARTICIPAR**

O botão deve levar diretamente ao checkout.

## **6\. EVITAR REPETIÇÃO**

A página deve parecer rápida.

## **7\. EXPERIÊNCIA VISUAL DO MAPA**

O elemento visual:

**FORMAÇÃO → 01 → 02 → 03 → 04 → 05 → 06 → PRIMEIRA OPORTUNIDADE**

deve se tornar um dos principais elementos gráficos da nova identidade da campanha.
